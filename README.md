# call-me

The `call-me` Agda library aims to provide the tools to
automatically generate call graphs from function definitions in
Agda. It does so by utilizing the
[Reflection](https://agda.readthedocs.io/en/stable/language/reflection.html)
machinery that Agda provides.

Having the call graph of a function as a data type allows for
further analyses of that function. It is especially useful for
time and memory complexity analyses. See
[The cost of everything: a lightweight approach to formal algorithmic complexity by Wouter Swierstra, 2026](https://zenodo.org/records/20506788).
